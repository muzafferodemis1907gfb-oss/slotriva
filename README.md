# Slotriva: Casino Games — GitHub Pages dosyaları

Bu klasör GitHub Pages web sayfasının köküne yüklenmek için hazırlanmıştır.

## Kurulum

1. `muzafferodemis1907gfb-oss/slotriva` deposunda `Add file → Upload files` bölümünü açın.
2. `index.html`, `slotriva-privacy-policy.html`, `slotriva-gizlilik-politikasi-TR-EN.txt` dosyalarını depo ana dizinine yükleyin (klasörün kendisini değil).
3. `Settings → Pages → Build and deployment → Deploy from a branch`, `main` ve `/(root)` seçip kaydedin.
4. Yayın tamamlandığında şu bağlantıyı doğrulayın: `https://muzafferodemis1907gfb-oss.github.io/slotriva/slotriva-privacy-policy.html`
5. Çalışan HTTPS bağlantısını Play Console gizlilik politikası alanında kullanın.

**Not:** Politikayı son AAB'nin gerçek veri/izin/SDK durumuna göre kontrol edin. Bu paket GitHub'a otomatik olarak yüklenmedi.
